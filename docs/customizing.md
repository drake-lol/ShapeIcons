# Customizing

Everything is generated by `tools/gen_icons.py`. Edit, then run `./build.sh --bump --install`.

## A new shape
Drop a square PNG in `shapes/`. See [shapes/README.md](../shapes/README.md).

## Change the colours
At the top of `tools/gen_icons.py`: `BG_FILL` is the dark colour behind glyphs. Each glyph has its own colour in `GLYPHS`.

## A new glyph
Add a line to `GLYPHS`: a name, a colour, and a list of drawing commands on a 24x24 grid (`s` stroke, `f` fill, `d` dot).
Copy a similar one, e.g. `"clock"`.

## Map another app to a glyph
Add its component to `APPS`, under the glyph you want:

```python
"camera": ["com.oplus.camera/com.oplus.camera.Camera", "com.example.cam/com.example.cam.Main"],
```

Find an app's component with `adb shell cmd package query-activities --brief -a android.intent.action.MAIN -c android.intent.category.LAUNCHER`.

## Cover every app on your phone
`python3 tools/bake_installed.py <serial>` (needs the app installed on that phone). Then `./build.sh --baked --bump --install`. Without `--baked` these icons are left out on purpose (they reveal which apps you
have), so never publish a `--baked` build.
The baked icons are kept in `tools/auto_icons/` and ignored by git.

## Check your changes
`python3 tools/check.py` runs automatically in `build.sh`. It fails if anything points at a missing icon.
